# PROJETO-DE-ANALISE-DE-DADOS
ANÁLISE DE DADOS

Projeto dividido em 10 partes, para facilitar montar o passo a passo e organizar do código.

Parte 1 - Carregamento da base de dados (Base_varejo.csv) e observação dos dados mostrados.

Parte 2 - Busca, análise e identificação dos problemas apresentados nos dados.

Parte 3 - LIMPEZA DE DADOS (removendo colunas vazias, tratando os valores nulos, removendo valores duplicados)

Parte 4 - VERIFICAÇÃO (Verificando a base após a limpeza dos dados)
