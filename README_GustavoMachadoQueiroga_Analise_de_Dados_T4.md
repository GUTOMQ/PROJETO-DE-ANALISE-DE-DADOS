Instruções para execução

Abra o Visual Studio Code (VS Code).

Abra a pasta do projeto no VS Code.

Abra o arquivo:
ProjetoVersãoFinal_GustavoMachadoQueiroga_Analise_de_Dados_T4.py

Verifique se o Python está instalado.

Verifique se a biblioteca Pandas está instalada. Caso não esteja, abra o terminal do VS Code e execute:
pip install pandas

Com o arquivo aberto, execute o código do início ao fim.

Execução pelo terminal

Também é possível executar o projeto diretamente pelo terminal, dentro da pasta do projeto:
python ProjetoVersãoFinal_GustavoMachadoQueiroga_Analise_de_Dados_T4.py
